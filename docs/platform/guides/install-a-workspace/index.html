Install Bullfrog on a workspace

Install Bullfrog on your Linux machine and connect it to a workspace in the Bullfrog platform.

Before you begin​

  • Ubuntu 22.04, 24.04 or 26.04, or Debian 12 or 13, on amd64 with systemd
  • Root access through sudo, and curl installed
  • A workspace created in the Bullfrog platform and its workspace token

Organization API tokens cannot enroll a workspace. Workloads with root, sudo, Docker-root access or CAP_NET_ADMIN can bypass Bullfrog.

Install the agent​

Replace the placeholder with your workspace token and run these commands on the machine:

export BULLFROG_WORKSPACE_TOKEN='<your-workspace-token>'
curl -fsSL https://api.bullfrogsec.com/install.sh | sudo --preserve-env=BULLFROG_WORKSPACE_TOKEN sh
unset BULLFROG_WORKSPACE_TOKEN

Sudo normally removes environment variables. --preserve-env passes the exported token to the installer. A missing token produces an error with instructions; the installer never prompts.

The export may save the token in shell history. unset clears the variable, not history. Do not share shell tracing output because it can contain credentials.

For a custom control plane, export BULLFROG_API_BASE with its HTTPS origin and fetch /install.sh from that origin. Preserve both variables with --preserve-env=BULLFROG_WORKSPACE_TOKEN,BULLFROG_API_BASE.

Verify the installation​

Read the machine's status:

sudo bullfrogctl status

Confirm that the state is active.

Apply a rotated token​

Rotating a workspace token immediately revokes the previous token. On an already-enrolled machine, replace the saved credential with the new token:

export BULLFROG_WORKSPACE_TOKEN='<your-new-workspace-token>'
sudo -v
printf '%s\n' "$BULLFROG_WORKSPACE_TOKEN" | sudo bullfrogctl replace-token --token-stdin
unset BULLFROG_WORKSPACE_TOKEN
sudo bullfrogctl status

Run these commands in Bash, where printf is a builtin, so the token is not passed as an external process argument. Confirm the state is active. Rerunning the installer alone does not replace a rotated credential: it reuses the saved token.

Update the agent​

An enrolled machine reuses its saved credential. Run the installer again without supplying a new token:

curl -fsSL https://api.bullfrogsec.com/install.sh | sudo sh
